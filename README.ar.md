**مكتبة فيديو محلية لنظام Windows فقط.** تصفح مقاطع الفيديو وشغّلها، ثم ابحث عن المشاهد حسب الأشخاص الظاهرين فيها. يمكنك مراجعة اقتراحات مطابقة الوجوه وتصحيحها داخل التطبيق.

## ما الذي يمكنك فعله

- تصفح مقاطع الفيديو في المجلدات التي تختارها وتشغيلها
- البحث عن أشخاص محتملين ومقاطع مرتبطة وأوقات ظهور الوجوه
- إيقاف التحليل مؤقتًا ومتابعته، وتعيين مطابقات الوجوه أو تقسيمها أو دمجها أو استبعادها يدويًا
- حفظ فهرس المكتبة على الكمبيوتر دون نقل مقاطع الفيديو الأصلية

المجموعات التلقائية اقتراحات تعتمد على التشابه البصري وقد تكون خاطئة؛ راجعها وصححها. لم تُقَس دقة مطابقة الوجوه. تتم المعالجة محليًا، ويقوم الإعداد الأول بتنزيل البرامج والنماذج المطلوبة.

## الإعداد على Windows

تحتاج إلى Windows ‏64 بت وPython 3.12 وPowerShell. شغّل الأوامر من مجلد المشروع:

```powershell
.\Scripts\setup_windows.cmd
.\Scripts\run_windows.cmd
```

الإعداد الافتراضي يستخدم وحدة المعالجة المركزية. لتسريع NVIDIA CUDA شغّل `.\Scripts\setup_windows.cmd -Gpu`. يتطلب TensorRT تثبيتًا منفصلًا؛ راجع [تفاصيل إعداد Windows](docs/WINDOWS_SETUP.md). لم يُختبر تنفيذ Windows أثناء التشغيل: لم تُشغّل اختبارات أو يُفتح التطبيق أو تُحلل مقاطع فيديو حقيقية.

## الخصوصية والنماذج

يُحفظ الفهرس والصور التي ينشئها التطبيق ضمن بيانات التطبيقات المحلية في Windows. لا يرفع التطبيق الفيديو أو بيانات الوجوه. ينزّل الإعداد نموذج FACE01 المثبت للوجوه اليابانية ونموذج MediaPipe لمعالم الوجه ويتحقق من بصمات SHA-256. لنموذج FACE01 شروط منفصلة؛ راجعها قبل الاستخدام. لا يغطي [ترخيص MIT](LICENSE) للمشروع نماذج أو تبعيات الجهات الخارجية.

## حالة المشروع

لم يُختبر تنفيذ Windows أثناء التشغيل: لم تُشغّل اختبارات أو يُفتح التطبيق أو تُحلل مقاطع فيديو حقيقية. هذا الإصدار المخصص لـ Windows لا يدعم التطبيق أو الإعداد السابقين لنظام macOS.
