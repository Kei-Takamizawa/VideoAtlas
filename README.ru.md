**Локальная видеотека только для Windows.** Просматривайте и воспроизводите видео, а затем находите сцены по людям, появляющимся в кадре. Предложения сопоставления лиц можно проверять и исправлять в приложении.

## Возможности

- Просмотр и воспроизведение видео из выбранных папок
- Поиск предполагаемых людей, связанных видео и времени появления лиц
- Приостановка и продолжение анализа, ручное назначение, разделение, объединение и исключение совпадений
- Хранение индекса на компьютере без перемещения исходных видео

Автоматические группы — это предположения по визуальному сходству, и они могут быть ошибочными. Проверяйте и исправляйте их. Точность распознавания лиц не измерялась. Обработка выполняется локально; при первой настройке загружаются необходимые программы и модели.

## Установка на Windows

Нужны 64-разрядная Windows, Python 3.12 и PowerShell. Запустите из папки проекта:

```powershell
.\Scripts\setup_windows.cmd
.\Scripts\run_windows.cmd
```

По умолчанию используется CPU. Для ускорения NVIDIA CUDA запустите `.\Scripts\setup_windows.cmd -Gpu`. TensorRT устанавливается отдельно; см. [подробности настройки Windows](docs/WINDOWS_SETUP.md). Реализация Windows не проверялась во время работы: тесты не запускались, приложение не открывалось, реальные видео не анализировались.

## Конфиденциальность и модели

Индекс и созданные изображения хранятся в локальных данных приложений Windows. Приложение не отправляет видео или данные лиц. Установка загружает закреплённые модели FACE01 для японских лиц и MediaPipe Face Landmarker и проверяет SHA-256. У модели FACE01 отдельные условия; ознакомьтесь с ними до использования. [Лицензия MIT](LICENSE) проекта не распространяется на сторонние модели и зависимости.
