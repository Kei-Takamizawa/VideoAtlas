VideoAtlas — локальное приложение для Windows, которое упорядочивает видео и помогает находить сцены по людям в кадре. Поддерживаются MP4, MOV, AVI, MKV, M4V и WebM. Видео определяется по хешу содержимого, поэтому простое переименование не запускает повторный анализ.

## Возможности

- Собирать несколько образцов лиц для каждого видео и отслеживать людей внутри него
- Осторожно сопоставлять людей, появляющихся в разных видео
- Проверять предложения и выбирать «тот же человек», «разные люди» или «позже» (клавиши S, D, L)
- Менять имена, объединять и разделять группы, исключать людей и выбирать представительное изображение
- Сохранять проверенные пары для оценки результатов сопоставления

Автоматическое объединение между видео выключено. Проведена оценка небольшой реальной коллекции, но текущие пороги пропускают многие совпадения. Точность с настоящими масками ещё не подтверждена. Имена файлов не используются для определения человека. Результаты и ограничения режима верхней части лица описаны в [состоянии реализации](docs/IMPLEMENTATION_STATUS.md).

## Начало работы в Windows

Требуются 64-разрядная Windows, Python 3.12 и PowerShell. Выполните команды в папке проекта:

```powershell
.\Scripts\setup_windows.cmd
.\Scripts\run_windows.cmd
```

Стандартная настройка использует CPU и загружает официальные модели с проверкой контрольных сумм. Интерфейс доступен на английском и японском языках. См. [инструкцию по настройке Windows](docs/WINDOWS_SETUP.md). Исходные видео остаются на месте, индекс хранится на компьютере. Приложение не отправляет видео или данные лиц. Для моделей и программ действуют собственные условия использования.
